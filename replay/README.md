# Differential replay

Run `npm run replay:generate` to compile four small Solidity implementations and execute the same fixed transaction corpus in isolated Hardhat EVM instances. Run `npm run replay:verify` to regenerate in memory and fail if any committed JSON/HTML output, public mirror, corpus copy, or source copy differs.

The cases cover deposits, ordinary withdrawals, pausing, an attempted privileged withdrawal, and missing pause-release coverage. The generator records actual local deployment and transaction receipts, code/source hashes, Solidity storage layouts, state snapshots, permission/capability observations, invariants, and corpus coverage. It emits the same inputs, both source implementations, transaction outputs, normalized report, and rerun instructions for public review.

The `honest-advance`, `incomplete-replay`, `undeclared-capability`, and `invariant-break` examples are synthetic reviewer demonstrations generated by reproducible local EVM execution. They are not production incidents, an independent security audit, exhaustive testing, or proof of complete correctness. The CI receipt marks that no independent hosted CI run is claimed.

Schemas are in `schemas/`; source is in `contracts/`; input corpus is in `corpus/`; deterministic output is in `generated/`. The Next.js static evidence copies are in `../frontend/public/evidence/` and `../frontend/public/replay/`.
